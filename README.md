# session-runtime-kit

Набор правил и скиллов для работы с агентами (Codex, Claude Code) в Orca. Агент сначала разбирается в
задаче и показывает план, меняет файлы только после твоего «да», ведёт доску задач и табло сессии,
крупную работу раскладывает по вкладкам Orca. Ставится на Mac одной командой.

## Поставить

Нужны Orca и Codex. Остальное команда поставит сама, в домашнюю папку и без пароля:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/avialtsin/session-runtime-kit/main/setup.sh)"
```

Что она делает:

- ставит доску задач Backlog.md (готовый файл с GitHub) и скилл Orca `orca-cli` (берёт из самой
  Orca), если их нет;
- скачивает пакет в `~/session-runtime-kit`. Скиллы ставятся ссылками на эту папку, не удаляй и не
  переноси её;
- кладёт правила в `~/.agents/AGENTS.md`; Codex читает их через `~/.codex/AGENTS.md`, Claude Code —
  через `~/.claude/CLAUDE.md`;
- ставит скиллы в `~/.agents/skills`, команду `artifacts` в `~/.local/bin`;
- для Claude Code заранее подключает строку внизу вкладки и запись табло.

Всё, что установка заменила, лежит копией в `~/.agents/session-runtime/backup/`.

После установки:

- открой новый терминал, чтобы подхватились новые команды;
- если установка написала «ВНИМАНИЕ» про `~/.codex/AGENTS.md`, у тебя уже были свои правила Codex.
  Перенеси их в `~/.agents/AGENTS.md` (выше блока session-runtime), удали `~/.codex/AGENTS.md` и
  запусти команду ещё раз.

## Обновить

Та же команда. Или:

```bash
git -C ~/session-runtime-kit pull && python3 ~/session-runtime-kit/install.py
```

## Как пользоваться

Открой проект в Orca, во вкладке запусти `codex` и говори обычными словами. Все команды начинаются с
`go`; скилл можно позвать и по имени: `$go-help`. Не знаешь, с чего начать, — «go help».

| Сказать | Что будет |
| --- | --- |
| «go help», «где мы» | где сейчас проект: задачи на доске, последние сессии, вкладки Orca; какие есть команды и что делать дальше |
| «go create repo», «заведи репо» | завести проект: git, `AGENTS.md`, доска Backlog.md, папка `sessions/`; по желанию репозиторий на GitHub и проект в Orca |
| «go mind» | разобраться, что делаем и зачем, и свести обсуждение в задачу |
| «go work» | запустить работу: одна вкладка или проджект и воркеры в своих деревьях Orca |
| «go final» | слить ветки этапа, собрать результат, закрыть вкладки |
| «go grooming», «груминг» | разобрать доску: что живо, что сделано, что выкинуть |
| «go doctor», «доктор» | проверить всё разом: установку, правила, скиллы и все проекты из Orca |
| «go doctor repo», «проверь репо» | подробно проверить один проект и поправить, что согласуешь |
| «go retro», «ретро» | разобрать свои диалоги с агентом за неделю-две: что он делает не так и что тебе нравится; подстроить правила под себя. Что улучшить в самом пакете — отдельный раздел, его можно переслать автору |

Доска задач проекта: `backlog board` в терминале или `backlog browser` в браузере.

Табло сессии — файл `sessions/NNN-…/artifacts.md` в проекте: что делаем, зачем, что решили, что
сделано. В Codex агент ведёт его сам, командами `artifacts`. В Claude Code табло пишется само и
видно в строке внизу вкладки.

## Свои правила

Установка держит правила блоком между метками `session-runtime:begin` и `session-runtime:end` в
`~/.agents/AGENTS.md` и при обновлении переписывает только этот блок. Свои правила (язык ответов,
аккаунт GitHub, привычки) пиши в тот же файл выше блока.

## Что можно добавить потом

- **GitHub из «заведи репо».** Без него проект заводится локально. Чтобы агент сам создавал
  репозиторий на GitHub, нужен GitHub CLI: поставить с https://cli.github.com и войти `gh auth login`.
- **Контекст кода перед крупной правкой** (скилл `agent-context-pipeline`). Ему нужен repowise; скилл
  сам предложит его поставить, когда понадобится.
- Скиллы, которым нужны личные ключи и доступы: расшифровка голосовых и видео (`go-transcribe`, нужен
  ключ Deepgram или Mac на M-чипе) и чтение своего Telegram (`go-telegram`). Захочешь — напиши,
  подключим.
