# Пример стартового задания

Задание вкладке из реального запуска в интернет-магазине (05.10.2026, имена обезличены), с
поправками по итогам: план до старта — в первом сообщении, связь — с пользователем, рабочее дерево и
вкладку создаёт координатор (`orca worktree create --agent claude --prompt`). Это иллюстрация, а не
форма: другой проект — другие проверки, выкладка, порты и правила.

```text
Задание: ты ведёшь очередь «Синк каталога» (TASK-1006 → 1010 → 1011 → 1012) в shop параллельно с тремя другими вкладками. Сначала разбор и план, работа — после «да» пользователя.

КОНТЕКСТ
Репозиторий ~/projects/shop (основная папка, ветка main). Доска Backlog.md переписана грумингом в поколение 1: TASK-1001…1017, порядок номеров — порядок очереди, связи проставлены (разбор — sessions/005-051026_Груминг-доски/обзор-доски_v1.md). TASK-1001 и TASK-1002 пользователь отложил — не брать. Правила проекта — AGENTS.md; работа с доской — `backlog instructions overview`, перед стартом задачи — task-execution, перед закрытием — task-finalization.

Соседи: shop-4c «Дизайн» (1003 → 1007 → 1008 → 1009), shop-77 «Адреса и SEO» (1004 → 1017), shop-c0 «Заказ и уведомления» (1005 → 1013 → 1014 → 1016).

ТВОЯ ОЧЕРЕДЬ
1. TASK-1006 Защита живого каталога от сбоев синка. Ночной синк пишет прямо в прод. Пропавшая цена: сначала тестом выясни, что происходит сейчас — buildVariantPrices при cost = null отдаёт пустой набор цен, а после TASK-002 флаг продажи требует цену; по аудиту товар остаётся с 0 ₽.
2. TASK-1010 Пересбор без потери фото, переименования, расписание — те же файлы синка, поэтому после 1006. Адреса товаров и разделов (handle) при пересборе не должны меняться: на них держатся ссылки и sitemap у shop-77. Расписание синка — решение пользователя.
3. TASK-1011 Фото: таблица, скрипт импорта с пробным режимом, источники и стиль — с пользователем. Подпись на витрине — только когда shop-4c сообщит, что TASK-1008 в main (она перестраивает все экраны).
4. TASK-1012 Акции и главная: бэкенд и инструкция владельцу — сразу; витрина главной — после TASK-1008.

СНАЧАЛА ПОНЯТЬ, ПОТОМ ДЕЛАТЬ
Актуальность задач пользователь подтвердил при раскладке. Первым делом, до глубокого контекста, быстро проверь карточки и последние коммиты: не сделано ли уже, не поменялось ли. Поменялось — сначала коротко скажи пользователю.
Собери контекст: AGENTS.md, ARCHITECTURE.md, задачи очереди целиком, аудит и разбор доски, закрытые задачи, на которые они ссылаются, затрагиваемый код (скилл agent-context-pipeline — только в своём дереве: на время индексации RepoWise прячет каталоги рабочего дерева). Разбери каждую задачу как продуктовую: что сейчас видит покупатель или владелец, зачем это магазину, что значит «сделано на 100%», включая проверку на проде, что нужно от владельца, риски и пересечения с соседями. Напиши план очереди: шаги, чем проверишь пункты приёмки, что спросишь у пользователя, где вливаешься и кого ждёшь. Покажи пользователю и начинай после его «да». До этого код не правь, статусы на доске не меняй, ничего не выкладывай.

КАК РАБОТАЕМ ВМЕСТЕ
- Ты запущена в своём рабочем дереве ~/orca/workspaces/shop/shop-sync (ветка <аккаунт>/shop-sync, от локального main). Весь код — только в нём, чтобы не мешать соседям. .env уже скопированы, pnpm install сделал setup-хук; npm install в design-prototype — за тобой.
- Доска — только в основной папке (cd <основная папка> && backlog …): в копии CLI выдаст новым задачам те же номера, что у соседей. Коммить там только свои файлы доски.
- Готово к сборке: главный сценарий задачи проходит руками на твоём стенде, типы и быстрые тесты твоей части зелёные, снят один кадр главного пути. Тогда — rebase на свежий main, быстрые проверки своей части, fast-forward в main из основной папки, и сообщение «готово к сборке»: что работает, что известно недоделанным. Телефон, темы, эталонные кадры и полный прогон — не твои, это делается один раз на сборке. Чужие незакоммиченные файлы не трогать, без amend. Не пушить.
- Выкладка — только deploy/deploy.sh из основной папки, с согласия пользователя и по одной вкладке: выкладка собирает всё, что лежит в основной папке. Синк на проде — тоже только с согласия.
- Порты: витрины у shop-77 (5174) и shop-4c (5175); бэкенд на 9000 один на всех.
- Номер папки сессии проверь и в деревьях соседей — вкладки берут номера одновременно.
- Вопросы, решения, данные владельца и отчёты — пользователю в своём чате. Соседям — только короткие уведомления по стыкам (влил, можно начинать); всё, что требует решения, — через пользователя.
- Неясно — спроси пользователя, вместе подумайте; не выдумывай. Сроков и оценок в задачах не писать.
```
